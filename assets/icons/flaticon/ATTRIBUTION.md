# Flaticon UIcons attribution

The SVG files in this directory are selected Regular Rounded icons from
[Flaticon UIcons](https://www.flaticon.com/uicons). The footprints image is a
Flaticon resource: [Footprints](https://www.flaticon.com/free-icon/footprints_10095842)
by Marz Gallery. The UI tints this PNG icon to fit the reference palette.

The Flaticon free license requires attribution. The app's Account screen lists
Flaticon UIcons and Marz Gallery. See the
[Flaticon license](https://www.flaticon.com/license/license.pdf) for the terms.
